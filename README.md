# Hi, I'm Daði

I'm a robotics engineer and research assistant at Aalborg University, working on autonomous space robotics in collaboration with ESA.

My work focuses on reinforcement learning, autonomous systems, robot simulation, computer vision and transferring algorithms from simulation to physical robots. I have worked with space robots, Boston Dynamics Spot, KUKA manipulators, assistive robot arms and robotic systems at CERN.

## Featured public projects

### [SKYWALKER](https://github.com/dadihrannar1/SKYWALKER-RL-1.0)

A dual-agent reinforcement-learning system that enables a free-floating robotic manipulator to crawl autonomously between structural anchor points. The system was trained in simulation and successfully demonstrated on physical hardware at Aalborg University and ESA's Orbital Robotics Lab.

### [Safe Navigation for Boston Dynamics Spot](https://github.com/dadihrannar1/spot-safe-navigation)

A safe data-driven navigation system for a Boston Dynamics Spot robot operating in dynamic environments. The project combines learned environmental predictions with optimisation-based motion planning and was validated experimentally on the physical robot.

### [Automated Dangerous-Goods Package Inspection](https://github.com/dadihrannar1/automated-dangerous-goods-inspection)

An RGB-D computer-vision pipeline for inspecting dangerous-goods packages using U-Net segmentation, OCR and geometric validation. The project grew from our first-place concept at the 2022 Future of Logistics Hackathon.
